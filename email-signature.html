How to install in Gmail
  1. Open this file in a browser, click Copy signature above (or select the preview and press Ctrl+C).
  2. In Gmail, go to Settings (gear icon) → See all settings → General.
  3. Scroll to Signature, click Create new, name it "StayAtFlorida".
  4. Click into the signature box and press Ctrl+V to paste.
  5. Under Signature defaults, set it for new emails and replies.
  6. Scroll to the bottom and click Save Changes.
