**Issues flagged for the future rebrand pass:**

1. **`Deluxe`** — adjective without proof, forbidden per BRAND_GUIDELINES `OTA platform titles` rule.
2. **`Majestic Sun Resort`** — misleading. `Majestic Sun` is a building within `Seascape Resort`; framing `Majestic Sun` itself as a resort is factually wrong. The actual resort name is Seascape.
3. **`Beach Front` two words** — inconsistent with the `Gulf-Front` convention we use on TW2111 (front-of-Gulf, hyphenated) and the more accurate framing for a directly-on-the-Gulf unit.
4. **No property-brand differentiator** — `Majestic Sun 811` is the canonical property brand per config.js + MASTER; only `Majestic Sun` (without the `811` unit designator) appears here.
5. **`8th floor` risk** — MS811's direct-site hero H1 currently reads `8th-Floor Gulf Views at Majestic Sun`, which violates the BRAND_GUIDELINES "no explicit floor number" rule. When the MS811 rebrand ships, this must be fixed on the direct site AND all OTA copy must ensure no floor number leaks into the Booking.com description. Currently no `8th floor` string appears on the live Booking.com listing — good baseline.

**Note on the aggregate risk:** the 5.5/10 aggregate is a critical variable to track. Any Booking.com rebrand work has to be paired with a review-solicitation strategy (#44) or the copy improvements will not translate to search-rank improvements. Booking.com's search algorithm weights guest-score heavily. Flag this to the owner before scheduling the MS811 rebrand pass.
